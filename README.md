# COMP9001-Final-Project
Project Title: The Midnight Spellbook - Four File Story Edition

Main File:
Run main.py

How to Run:
1. Put all four Python files in the same folder:
   - main.py
   - models.py
   - game_data.py
   - save_system.py
2. Open the terminal in this folder.
3. Run:
   python3 main.py

Important:
Do not upload only main.py if using this version. The four .py files must stay in the same folder.

Required Libraries:
No external libraries are required.
This project only uses Python built-in libraries: copy, random, json, os.

Advanced Concepts Demonstrated:
1. Object-Oriented Programming: Player, GameJournal, and MidnightSpellbookGame classes.
2. File I/O with JSON: save_system.py saves and loads game progress.
3. Exception Handling: input validation and save/load error handling.
4. Dictionaries, lists, and nested data structures: rooms, characters, puzzles, clues, trust values.
5. Modular Program Structure: code is divided into four clear Python files.

Game Description:
The Midnight Spellbook is a text-based magical mystery game. The player explores Moonstone Academy, collects evidence, earns character trust, solves puzzles, learns spells, and makes a final judgement. The story includes a time loop, a false suspect, emotional motivation, and multiple endings.

Best Ending Hint:
Talk to characters using empathy or evidence. Avoid accusing them too early. Final answers are:
1. Professor Elowen
2. To save Seren's trapped memory
3. The grief binding Seren to the Codex
